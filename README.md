# Movie Recommendation System

Analytical project implementing a recommendation system based on similarity metrics and collaborative filtering concepts.

---

## Overview

This project develops a recommendation engine using user ratings and similarity matrices.

Main tasks include:

- Data preprocessing
- Vector normalisation
- Cosine similarity
- Correlation analysis
- Movie recommendations
